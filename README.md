# video2gif

Видео и картинки → GIF. Быстро, локально. Плюс скачивание видео и музыки.

**by DeepSeek v4.1 flash & arsikfox14 & dismasdismavich**

Версия **4.0**: одна сборка **Video2Gif.exe** — с TikTok, YouTube,
Spotify и другими сайтами.

Установка не нужна: FFmpeg и yt-dlp находятся внутри exe.
Права администратора не требуются.

## Возможности

- Видео → GIF: MP4, MKV, AVI, MOV, WEBM, M4V, WMV, FLV, MPG, TS, 3GP, OGV.
- Картинки → GIF: PNG, JPG, WEBP, BMP, TIFF, TGA, AVIF.
- Качественный GIF через палитру: palettegen + paletteuse, два прохода.
- Sierra-сглаживание по умолчанию, 256 цветов.
- Частота кадров 1–60, по умолчанию 30.
- Начало и длительность фрагмента (0 или пусто — весь клип), ширина результата.
- Бесконечный цикл или один проигрыш.
- Быстрый режим — один проход вместо двух.
- Прогресс, отмена, предпросмотр, сохранение и открытие результата.
- Шесть режимов оформления: авто по дате Windows (по умолчанию), светлая,
  тёмная, новогодняя, хэллоуинская и **GTA 6** (неоновый градиент) —
  выбор в настройках (шестерня в шапке). Заголовок окна окрашивается
  в цвет выбранной темы.
- Автообновление с GitHub: проверка при запуске и кнопка
  «Проверить обновления» в настройках.
- Перетаскивание файла в окно или на exe.
- Открытие файла, переданного аргументом командной строки.
- Мини-игра «Змейка» — значок мышки в шапке, интернет не нужен.

  проекта открываются в браузере.

## Скачивание

Меню **«Скачать»** в главном окне:

- **YouTube и другие сайты** — YouTube, TikTok, SoundCloud, VK и тысячи
  других сайтов. Ссылки TikTok качаются встроенным способом (без водяного
  знака, вместе с фото-постами), остальные — через yt-dlp. На выбор видео
  MP4 или музыка MP3. Если ссылка ведёт на плейлист, для него создаётся
  отдельная папка с названием.
- **Музыка из Spotify** — ссылка на трек, альбом или плейлист.
  Программа читает открытые метаданные страницы Spotify, ищет трек
  на YouTube с проверкой длительности и сохраняет MP3 или WAV.
  Альбом и плейлист сохраняются в отдельную папку.
  Это не прямое скачивание из Spotify: DRM не обходится.

Все скачанные файлы и готовый GIF по умолчанию сохраняются
на **рабочий стол**. Папку можно изменить в окне сохранения.

Во время скачивания под полосой загрузки показывается этап и процент,
чтобы было видно, на чём программа остановилась.

## Как запустить

1. Скачать `Video2Gif.exe`.
2. Двойной клик.
3. Перетащить видео или картинку в окно.

Требования: Windows 10/11, 64-бит, .NET Framework 4.8 (уже входит в Windows).
Интернет нужен только для скачивания.

При первом запуске FFmpeg и yt-dlp распаковываются в
`%LOCALAPPDATA%\Video2Gif`. Повторно распаковываться не будут.

## Обновления

Программа проверяет новые версии на GitHub при каждом запуске, а также
по кнопке **«Проверить обновления»** в настройках. Если вышла новая версия,
появляется окно с её номером и описанием: можно скачать и установить сразу
или отложить.

Обновление скачивается во временную папку, заменяет текущий `Video2Gif.exe`
и перезапускает программу. Настройки, темы и скачанные файлы не затрагиваются.
Счётчик «показать один раз» хранится в `%LOCALAPPDATA%\Video2Gif\update.txt`.

Для работы автообновления релиз на GitHub должен содержать файл
`Video2Gif.exe` (подойдёт и `Video2Gif-3.x.zip` — программа достанет exe
из архива), а тег релиза должен быть новее установленной версии,
например `v4.0`.

## Сборка из исходников

Исходники лежат в корне репозитория (C#, WinForms, .NET Framework 4.8).
Компилятор берётся из Windows: `csc.exe`, отдельный SDK не нужен.

1. Положить в папку `bin` в корне проекта (рядом с папкой `src`)
   64-битный `ffmpeg.exe` — https://ffmpeg.org (сборка gyan.dev) —
   и `yt-dlp.exe` — https://github.com/yt-dlp/yt-dlp/releases/latest

2. Запустить:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Собирается `Video2Gif.exe`.

Скрипт сжимает FFmpeg и yt-dlp в `build\*.gz`, рисует иконку и собирает exe
в корне проекта. Файлы `.cs` должны быть в UTF-8 с BOM.

Самопроверка без графического интерфейса:

```powershell
Video2Gif.exe --selftest
```

Результат пишется в `%TEMP%\video2gif-selftest.log`.
